    The full live browser report: every check this package can run, grouped by domain, plus controls for the two-visit storage persistence test.

    Everything it renders comes from startUpdatingMinutia, so it re-renders on its own as automation checks are triggered. Call startUpdatingMinutia directly instead when you want the data without the UI.

    The persistence marker is written into the page's minutiaPersistenceMarker search param, so that reloading (or closing and returning to) the page verifies the same marker that was seeded.
