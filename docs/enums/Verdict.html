    Enumeration Verdict

    The single result vocabulary every check in this package reports through. The underlying techniques disagree about what a result means natively (a fingerprint either matches a reference or does not, an automation probe may never fire at all, a bot signal is weak or strong), so each domain maps its own outcome onto these four values and consumers only ever handle one scale.
